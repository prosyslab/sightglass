# cvc5

This benchmark builds a small Sightglass wrapper around the cvc5 SMT solver's
C++ parser API. The wrapper parses and executes a deterministic embedded
SMT-LIB workload from SMT-COMP, with Sightglass timing around command parsing
and execution.

The Docker build clones cvc5 release `cvc5-1.3.4`, builds it with Emscripten,
installs the generated `cvc5::cvc5` and `cvc5::cvc5parser` CMake targets, and
then links `benchmark.cpp` against those targets.

## Porting notes

This is intended to avoid SQLite-style `.wat` surgery. The wrapper imports
`bench.start` and `bench.end` directly via `sightglass.h`, and feeds cvc5's
parser with `InputParser::setStringInput`.

The workload is embedded in `default_smt2.h` instead of loaded from
`default.smt2` at runtime. Direct Emscripten file I/O left unsupported
`env::__syscall_faccessat` imports without WasmFS. With WasmFS, the module
could not see Sightglass's WASI preopened working directory. Emscripten
`--embed-file` added an unsupported `env::_emscripten_fs_load_embedded_files`
import. The embedded string is therefore the current standalone-compatible
approach.

## Workload

The embedded workload is:

`non-incremental/QF_BV/20221214-p4dfa-XiaoqiChen/Composition/simple_bit8_na1_nr1_twocond.smt2`

This is an industrial QF_BV SMT-COMP benchmark generated by P4DFA for
synthesizing an isomorphic mapping for state-machine transitions with hardware
arithmetic circuits in programmable switches. It is 20 KiB and has expected
status `sat`.

You can download the whole SMT-COMP benchmark set using:

```sh
curl -LO https://zenodo.org/records/16740866/files/QF_BV.tar.zst
````
`

The larger P4DFA mobile-device input
`MobileDevice/mobiledevice_bit8_na1_nr1_twocond.smt2` is more realistic, but it
did not finish within a minute with native cvc5 during initial screening. That
makes it too large for Sightglass's default repeated-run setup until the
benchmark has a custom iteration count or an alternate harness mode.
